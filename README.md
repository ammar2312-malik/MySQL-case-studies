# 🚀 MySQL Case Study Portfolio

A collection of **50+ real-world SQL business problems** solved using **MySQL 8.0** across multiple industries including Manufacturing, Airlines, Oil & Gas, Supply Chain, and Aviation.

This repository demonstrates practical SQL skills through industry-focused case studies, covering concepts from basic querying to advanced analytics, query optimization, transactions, and database administration.

---

## 📌 About This Repository

The goal of this repository is to strengthen SQL problem-solving skills by working on realistic business scenarios that simulate challenges faced by Data Analysts, Business Analysts, and Data Engineers.

Each case study follows a structured approach:

* Business Background
* Problem Statements
* SQL Solutions
* Query Explanations
* Key SQL Concepts

The difficulty progresses from **Beginner → Intermediate → Advanced**, making it suitable for both learning and interview preparation.
